# zplayer link gaps

Generated by `src/port/tools/zplayer_link_gaps.py` from the link of the `zplayer`
target in a tree that has only the committed zcport parts (foundation, fixmath,
primitives in progress) and the integration work. Every symbol below is referenced
by the player (or by the integration files) and defined nowhere yet. Re-run the
script on a fresh link log after merging modules:

```
cmake --build build-wt --config Release --target zplayer -- -m -v:minimal -nologo > link.log 2>&1
python -I src/port/tools/zplayer_link_gaps.py link.log docs/zplayer-link-gaps.md
```

"Referenced from" names the object files (game sources) that use the symbol.
Symbols that the modules need from each other are not visible here; they show up
in the first link after the merge.
